# 当前 DMM 与官方源码、ICCV 2025 方法的对照审查

日期：2026-10-06。范围：读取当前源码、官方基线、论文原文和已有验证记录；未修改模型实现，未启动训练，未重新验收已认可的旧 synthetic sanity check。

## 1. 结论先行

当前版本可以概括为：**官方 DMM 的隐式组件网络 + 新的单颌训练流程 + 静态双颌多视图拟合流程**。

- **核心模型仍是 DMM。** 没有另造一个从照片直接预测牙齿的网络，没有完成形状与排列的解耦，也没有学习跨颌咬合先验。
- **数据流和参数设计符合当前收窄后的任务。** 两颌分别训练，拟合时冻结网络，使用已知相机、逐牙掩码和跨视图共享的两颌参数重建静态场景。
- **实现借鉴了 ICCV 论文，不能称为完整复现。** 保留了 DMM、软语义、几何 XY、匹配、先验正则的主要思路；表面求导、OT/Warp、先验和恢复策略采用了本项目的实现选择。FLAME、动态跟踪、牙齿与脸部接触等不在当前范围。
- **目前证据支持接口和部分数值链路可用，尚不足以宣布重建质量达标。** 新训练流程实质改变了原训练配方；细网格整图抗锯齿梯度仍有明确限制；现有短程拟合没有证明稳定收敛。正式长训前应先处理这些与主任务直接相关的问题。

这里需要纠正此前解释中的混淆：**“静态上下颌”表示同一组照片共享一套形态和位姿，不表示这些位姿事先已知。** 当前约定允许优化每颌一个整体位姿，符合原需求。“连两颌位姿也固定为已知”只能是额外的受控验证条件。

## 3. 先把三件事分清

```text
三维上颌训练数据 ──训练──> 上颌 decoder + 训练码统计 ──> upper bundle
三维下颌训练数据 ──训练──> 下颌 decoder + 训练码统计 ──> lower bundle
                                                        │
已知相机 + 同一静态状态的多视图逐牙掩码 ──────────────────┤
                                                        ↓
                          冻结两个 decoder，优化该病例的两颌位姿和牙齿码
                                                        ↓
                                         上、下颌三维表面及拟合诊断
```

| 名称 | 实际含义 | 当前是否需要 |
|---|---|---|
| 上下颌独立训练 | 分别学习两套单颌先验；不要求训练病例逐行配对 | 需要两套合规先验，才能执行当前双颌场景拟合 |
| 双颌场景组装 | 放入同一世界坐标和深度缓冲，正确处理两颌及牙龈遮挡 | 需要 |
| 双颌联合拟合 | 共同解释照片，但仍使用各自的位姿和 latent | 需要；静态场景也需要 |
| `train-dual` | 自动按 upper → lower 调用两次独立训练并管理续跑 | 可选便利入口；手动分别训练也可以 |
| 可选跨颌防穿插 | 惩罚两颌表面的穿入代理 | 可选；不要求张开的上下牙接触 |
| 联合训练一个双颌模型 | 学习跨颌相关性或咬合分布 | 没有实现，当前范围也不要求 |
| 动态下颌跟踪 | 每帧具有不同的关节/下颌运动 | 当前不需要 |

因此，之前“5. 扩展上下颌训练与联合拟合”这个合并标题容易误导：**可选的是调度入口和防穿插项，基础双颌支持已经属于主流程。**

## 4. 相较官方 DMM 改了什么

### 4.1 网络及原生入口

官方已跟踪文件实际修改了三处：

| 文件 | 当前修改 | 判断 |
|---|---|---|
| [networks/dmm_net.py](../third_party/DMM/networks/dmm_net.py) | 显式 `arch`、FDI/维度校验、组件查询与整体查询；返回组件场及混合权重，保留梯度；新路径显式管理设备 | 为上下颌数据及图像拟合提供必要接口；网络主体沿用官方实现 |
| [utils/math.py](../third_party/DMM/utils/math.py) | 零角度附近稳定的 SE(3) 指数映射及变换函数 | 必要的数值修正，支持一阶/高阶求导 |
| [train_dmm.py](../third_party/DMM/train_dmm.py) | 增加 `--config` 原生训练路径，同时保留旧 `-e` 路径 | 直接改源码入口；新流程实现在同一源码树中 |

`deform_net.py`、`meta_modules.py`、`modules.py`、`mlp.py` 等核心网络文件没有相对基线的修改。HyperNetwork、组件 deformation/reference SDF、SDF correction 和 blending 结构仍在。

需要准确称呼 latent：它同时影响空间变形、SDF 修正和混合权重。牙齿组件输出的 SE(3) 参数还是依赖查询点的变形场，不能解释为每颗牙一个独立刚体姿态。当前 `shape` 阶段实际上是 **latent-only 阶段**，不能承诺只改牙冠形态而不改排列。

这是当前 `coupled_component_dmm` 的已知性质，不构成对 ICCV 思路的违背。增加形状/排列解耦会是另一项模型研究，当前不应把它当作复现论文的前置条件。

### 4.2 数据与训练：改动超过“支持下颌加载”

新增 [arch_dataset.py](../third_party/DMM/data/arch_dataset.py)、[arch_training.py](../third_party/DMM/training/arch_training.py) 和上/下颌 specs。它们提供 manifest、显式存在性、患者划分、文件哈希、固定毫米尺度与 canonical 坐标、独立训练及 bundle 导出。

尺度约定为 `1 model unit = 50 mm`；这只是新流程的数值换算。旧权重、旧每例归一化数据不会因此自动具有正确毫米尺度。官方示例以上颌为主，但官方网络标签本身可配置，不能笼统说官方架构不能表示下颌。

**当前训练不是官方训练配方的等价迁移：**

| 项目 | 官方旧路径 | 当前 manifest 路径 | 影响 |
|---|---|---|---|
| 点采样 | 表面及正/负场外样本按原比例抽样 | 每个存在组件等额表面点，加一个 off-surface 点池；无正负配额约束 | 改变各牙和空间区域的监督分布 |
| 损失归一化 | 多处用掩码置零后对全部点平均 | `selected_mean` 对有效点平均；整体表面/非表面项分别归一化 | 即使保留名义系数，相对强度也发生变化 |
| 组件聚合 | 原路径也会除以组件数量 | 组件均值 | 不能把“组件平均”说成当前才新增的修正 |
| 优化器 | deformation/reference/latent 分组学习率，并使用 StepLR | 一个 Adam、一个恒定学习率 | 收敛行为与官方不同 |
| latent 初始化 | 标准差 0.002 | 标准差 0.001 | 初始先验分布不同 |
| 训练组织 | 原 batch/DataParallel 等路径 | 每步一个病例，显式单设备 | 吞吐及梯度统计不同；没有新路径的 DDP/AMP 支持 |
| 模型选择 | 本报告不替原路径作质量保证 | `best_train.pth` 仅按训练损失选择 | 当前新路径缺少独立验证集评价和据此选模 |

原来的 SDF、法线、Eikonal、修正场、变形正则、混合分类、中心及 latent 等损失家族仍保留；但**家族和系数相同不等于数值目标相同**。有效点归一化有工程动机，不能在没有对照的情况下认定它优于原训练或无需重新调权。

这是正式长训前最值得先核实的一项：新训练管线能跑通，不表示已经证明能训出与官方相当或更好的牙齿先验。

### 4.3 新增的多视图重建流程

| 模块 | 新增能力 | 与当前任务的关系 / 限制 |
|---|---|---|
| [bundle.py](../third_party/DMM/dmm/bundle.py)、训练导出 | 权重、尺度、组件身份、来源绑定；训练码均值与正则化协方差 | 支持可追溯部署；新 bundle 不自动兼容旧实验 |
| [scene.py](../third_party/DMM/dmm/scene.py) | 两个独立 decoder、两套 latent 和整体 SE(3)；统一坐标、共同深度；固定相机 | 符合静态双颌要求；参数跨视图共享 |
| [surface.py](../third_party/DMM/dmm/surface.py) | MC 表面和局部隐函数求导桥接 | 把图像损失接回 DMM latent；采用局部曲面、固定拓扑的梯度近似 |
| [rendering.py](../third_party/DMM/dmm/rendering.py) | nvdiffrast 软逐牙语义、几何投影 XY、牙龈及双颌遮挡 | 主流程需要；CPU 路径仅供诊断，不能替代 GPU 轮廓梯度 |
| [semanticxy.py](../third_party/DMM/dmm/semanticxy.py) | SemanticXY、部分 OT、Warp、未匹配质量与 dense loss | 对论文思路的具体工程化版本，详见下一节 |
| [fitting.py](../third_party/DMM/dmm/fitting.py) | 位姿→latent→联合阶段、分块更新、回溯、重提取网格、续跑与诊断 | 拟合时网络冻结；没有按照片重新训练 decoder |
| [recovery.py](../third_party/DMM/dmm/recovery.py) | 目标可见但预测缺失时，使用组件辅助投影、深度约束和粗平移初始化 | 帮助重新出现观测目标；不是恢复从未观察区域的真实解剖 |
| [collision.py](../third_party/DMM/dmm/collision.py) | 可选双向跨颌表面穿入代理 | 默认关闭；不是论文 tooth–face contact loss |
| [dual_training.py](../third_party/DMM/training/dual_training.py) | 两次训练的调度、跨颌患者划分校验、完成结果复用和续跑 | 可选；没有增加跨颌模型参数或联合学习目标 |
| CLI、validation、provenance 等 | 输入契约、哈希、来源和状态检查 | 支撑上述流程，可运行不等于质量通过 |

补充边界：

- 默认 28 颗恒牙，牙龈有几何但在牙齿语义中归背景；缺牙由显式 presence 给定，当前不联合推断未知缺牙。
- 牙龈码固定为训练均值。完全无观测牙位的 q 在拟合中冻结；默认初值为均值。未观察表面主要由先验补全，不能声称由照片确定。
- 当前 `fit-scene` 需要两个 bundle，并要求每颌至少两个不同可见相机视角；支持独立训练不等于拟合加载器也已提供独立单颌模式。
- 两颌相对位姿通过两个世界位姿导出；在优化迭代中可以变化，最终各视图使用同一个结果。如果未来要求“已知相对位姿、只优化共同整体位姿”，当前没有专门的绑定参数化。
- nvdiffrast 另有 SM 12.x 原子操作兼容修改，属于渲染依赖适配。已有本机 RTX 5050 证据，不代表目标 RTX 5090/WSL 已验证。

## 5. 与 ICCV 2025 论文逐项对照

论文完整任务是视频中的脸部与牙齿重建及动态捕捉；本项目选取其中适用于静态多视图牙齿的部分。因此，“符合当前简化任务”和“完整复现论文”必须分开评价。

| 论文方法 | 当前实现 | 判断 |
|---|---|---|
| §4.1.1：DMM 隐式场、MC 网格、NIE 梯度 | DMM + MC + 自行实现的局部隐函数梯度桥 | 方向一致；不能称为已等价实现论文 NIE |
| §4.1.2：上下颌和 FLAME skull/jaw 对齐及绑定 | 独立世界位姿，无 FLAME、关节绑定 | 符合当前静态牙齿范围；未复现视频动态系统 |
| §4.2.1，式 4–5：混合权重生成软语义、可微渲染、语义损失 | 保留软语义及物理深度遮挡，损失增加归一化和显式背景处理 | 主思路一致，损失数值定义有改动 |
| §4.2.2，式 6–7：几何投影 XY + 语义、OT 对应、Warp | 几何 XY、部分软 OT、双向重心 Warp | 合理改编；采样、质量、未匹配项及对称化是项目选择 |
| §4.2.3，式 8：原始 latent 的 L2 prior | `z = mu + Lq`，对 q 的平方按维度/组件平均 | 改成训练分布标准化后的正则，不是同一个目标；也不证明码分布为高斯 |
| §4.2.3，式 9：牙齿与脸部/嘴唇穿插约束 | 可选上下颌穿插代理 | 约束对象不同，不能视为论文 contact 的实现 |
| §4.2.4，式 10–11：face-vanishing / teeth-hiding | 组件投影与深度恢复，无脸部语义或几何 | 解决部分“预测不可见”问题，未复现论文的两种脸部遮挡策略 |
| §5.1：第一阶段身份参数跨帧共享，随后动态逐帧与全局优化 | 静态全部视图共享两颌参数，采用位姿/latent 分阶段拟合 | 与第一阶段思想一致；动态后续步骤不需要照搬 |
| §5.1.1：脸部 RGB、光照、纹理、landmark 等 | DMM 拟合入口接收已处理掩码及相机 | 当前简化任务可省略；不能宣传为完整 RGB 到动态人脸牙齿系统 |
| §5.3–5.4：重建质量及消融 | 接口、梯度和短程夹具测试 | 证据等级不同，尚未获得论文同类的牙齿几何质量证据 |

### 当前 SemanticXY 的确切选择

当前算法名为 `partial_soft_semanticxy_v1`：

- 28 通道条件前景软语义；XY 使用图像中心和平面对角线归一化。
- 默认语义权重 4、XY 权重 1；语义距离使用半 L1。
- 每 FDI 默认 16 个确定性采样点，质量保留前景面积相对有效像素的比例。这里的“质量”指 OT mass，不是照片质量评分。
- 未匹配项使用 dustbin，默认代价 0.75、熵参数 0.05；使用 Sinkhorn 和数值修正，显式记录低匹配/不收敛状态。
- 匹配计划不反传，利用冻结对应计算双向重心 L1 Warp；保留 dense 语义及未匹配约束，视图等权平均。
- dense 项对包含背景的通道做 `0.5 × L1 / 有效像素数`。与论文直接描述的牙齿语义 L1 求和不相同。

这些值明确了工程实现，但没有从论文实验中获得“最佳权重”的保证。软语义权重也不等于严格禁止跨 FDI 对应。论文未明确给出的采样和 OT 超参数，不能擅自当成论文强制要求。

论文的几何指标主要评价可见牙齿区域，且讨论了仅看该指标无法覆盖遮挡策略效果。因此也不能用论文结果推断本项目已能准确恢复未观察牙面、完整咬合或绝对位姿。

本次没有重新运行上述实验，也没有把已认可的旧 sanity 结果作为新接口、新训练流程或新双颌模型的验收结果。

### 按主任务影响排序

1. **训练配方尚未完成质量论证。** 确定有效点归一化后的权重、采样和学习率策略，并加入独立验证与选模；否则长训难以判断问题来自模型还是新配方。
2. **真实牙齿表面上的拟合稳健性尚未证明。** 局部可微桥和回溯已有实现，但细网格轮廓梯度、初始化范围、latent/整体位姿互相补偿仍会影响收敛。
3. **普通照片的脸部/嘴唇遮挡尚未由此 DMM 流程建模。** 受控静态合成范围可接受；走向真实照片时，需要可信遮挡区域输入或相应建模，不能只以双颌深度代替。
4. **不可见解剖仍依赖先验。** “可见性恢复”需要改为准确解释：找回目标中已可见、但当前预测未出现的牙齿。它不是恢复无图像证据区域的真实性保证。
5. **文档状态落后。** 早期参数约定仍写“完整图像拟合器待实现”、渲染待接入等，后续模块文档和源码已更新。它们是不同时间的状态快照，不能拼成一份当前待办清单。

## 7. 接下来应采用的明确边界

当前主线继续保持：**已知相机、静态双颌、已知存在性、逐牙语义观测；独立先验训练后，冻结网络进行病例拟合。**

保留两颌独立模型、共享视图参数、语义渲染、SemanticXY、先验和分阶段优化。将 `train-dual` 调度与跨颌防穿插清楚标为可选。FLAME、动态 jaw tracking、跨颌联合先验、形状/排列解耦均不作为这一阶段必须完成的项目。

在正式长训前，优先把**单颌训练配方与独立验证**说明白、实现好，再对真实牙齿网格上的拟合梯度/下降行为做针对性核实。新增验证针对新能力，保留已认可的旧 sanity 结果，不重开它的验收。

最终判定：**当前实现与收窄后的研究路线一致，但训练与重建质量证据未闭环；它是论文启发的静态牙齿重建实现，不能标记为论文完整复现或全任务验收完成。**
