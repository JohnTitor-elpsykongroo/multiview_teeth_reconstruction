## 尺度和坐标

### 毫米几何作为唯一原始几何基准

先按明确单位证据将输入变为 `x_mm`，记录原单位与换算系数。OBJ 本身不携带可靠单位，牙弓宽度只能发现异常，不能独立证明 mm。保留原始顶点，不按包围盒逐轴归一化，不对单颗牙分别缩放，也不把牙齿移动到规则牙弓。

主线对每个病例只施加一个整颌相似变换：

\[
x_{model}=s_i R_i x_{mm}+t_i,\qquad
x_{mm}=R_i^T(x_{model}-t_i)/s_i,
\]

其中 `s_i > 0`、`det(R_i)=+1`。导出 `s_i`、`R_i`、`t_i`、4×4 矩阵及逆矩阵；单位换算与相似变换分别记录。

`s_i` 的单位是 model/mm，因此病例内一个 model 单位对应 `1/s_i` mm。相似归一化后的数据不能继续标记为固定 `model_unit_mm=50`，不能直接塞入当前强制 50 mm 的 R4 bundle 契约。以后部署到没有真值尺度的新患者时，需要独立的尺度估计或标定；不能从被移除的尺度凭空恢复真实牙列尺寸。

参考牙列从原始训练病例中选择：完整覆盖、表面质量好、身份明确、尺寸靠近训练群体中部。优先检查旧上颌参考 `6XSU5W4B_upper` 是否仍满足条件；它不是自动指定的合格参考。下颌独立选择，不能简单把上颌参考翻转后充当下颌。

参考规范化沿用旧版思路：旋转到确认的解剖方向，以包围盒中心平移，最长边缩放到约 1.90 个 model 单位，留 0.05 两侧裕量。每个病例随后按质心对齐到这个冻结目标，不再独立按包围盒二次缩放。[S3]

域检查以全部被保留的真实几何为对象，不只查随机采样点。主线初始域为 `[-1,1]^3`。如合格训练几何仍超出，先排查扫描底座、方向和异常离群点；若确需扩展域，建立新的 profile，统一修改空间采样、训练和提取域并重新审核。绝不裁点或 clamp 顶点来“通过”。验证/测试越界保留为失败，不据此调整已冻结参考或域。

**视觉验收**：毫米尺寸图、规范化前后同牙的比例检查、`s_i` 分布与极值病例、逆变换后的原始网格叠加。建议浮点往返误差以 `max(1e-5 mm, 1e-6 × 包围盒对角线)` 作首批工程检查值；这是数值一致性阈值，不是牙齿重建精度标准。

### 独立的固定毫米尺度对照

保留与主线相同的原件、语义、法线和源空间采样蓝图，将对齐限制为刚性，并用统一常数换算到 model 坐标。它用于以后隔离“移除全局大小变化”的影响，不作为首批默认发布数据。只有恒定 50 mm 且其余接口也满足 R4 约定的对照，才可能使用当前适配器；仍须验证，不自动兼容。

## 牙号和表面身份

FDI 以患者视角定义。上颌右侧 11–17、左侧 21–27；下颌左侧 31–37、右侧 41–47。界面标出患者左右，不以屏幕左右猜牙号。镜像映射为 `11↔21 … 17↔27`、`31↔41 … 37↔47`，0 保持 0。

原始 JSON 的 `labels/instances` 必须与 OBJ 顶点逐项对应。读取时关闭会重排/合并顶点的自动网格处理，或保留经过验证的一一映射。核对病例、上下颌、长度、合法标签、实例与牙号关系；冲突进入隔离，不自动改号。0 只表示来源中的非牙组织候选，须视觉确认牙龈、腭部及扫描底座，未知标签不能转为 0。

面语义采用独立置信度：三个顶点同号为 strict；两个同号为 boundary-majority；三个不同为 ambiguous。面积质心只用 strict 面，按三角形面积加权，不用顶点均值或随机点均值。对齐与中心监督使用同一质心定义。[S4]

主线表面库存允许经审核的多数票边界面，以延续旧版并避免整圈删去龈缘。所有这类点保存原面三顶点标签、置信度和来源。ambiguous 面保留在几何中，但不导出到旧接口的有标签训练点中；不得用 `label=-1` 把未知表面冒充非表面。记录逐牙排除面积及空间分布，若造成重要牙尖/沟裂/龈缘缺口，该例不能靠补点配额放行。

`present / absent / unknown / truncated` 在源记录中分开。只有明确缺牙才标 absent；残冠、扫描未覆盖、标签失败、某牙所有面被过滤，都不能直接当成缺牙。如果目标训练接口只支持二值 presence，带未决状态的病例暂不导出。

首批 14 牙位主线保持对含智齿病例的独立隔离，保留其来源及排除原因；不把 18/28/38/48 改为牙龈，也不静默切掉后训练。之后是否纳入需另定保留/裁剪及新增边界的契约。

**视觉验收**：四视图逐牙颜色及数字、单牙隔离图、实例连接分量、牙间与龈缘边界放大图；报告每颗牙 strict/boundary/ambiguous 面积和缺失状态。异常多连通组件须区分合理标签碎片和误标，不能一律取最大组件。

## 原表面和法线

几何清理默认只识别非有限值、退化面、重复面及异常拓扑，并保留完整操作记录。无面积退化面、同向重复面可在派生副本中确定性移除；反向重叠面、非流形区域、局部缺面和正面积面删除须先查看。首批不平滑、不重网格、不 Poisson 重建、不封牙冠孔洞，不用水密代理替换表面监督。允许扫描底部开口，它不是自动补洞的理由。

从面顶点叉积计算法线。共享流形边相邻面应具有相反的有向边；在连通组件内检查绕序一致性。局部一致并不能证明整体向外：对开口扫描，签名体积、质心径向点积、邻例法线比较都仅作告警证据，不能单凭任何一个量自动翻转整例。结合牙冠外表面、腭面、舌侧、切片和面剔除显示判定方向，必要时记录连通组件的整体翻转。不得逐点径向翻转来凑出“向外”。

正比例相似变换下：`n_model = normalize(R_i n_mm)`，不加平移，不把尺度乘到单位法线上。一般仿射形式用逆转置后归一化；主线禁止各向异性缩放。每次变换都以变换后面叉积重新验证方向。

镜像用 `M=diag(-1,1,1)`：点用 `Mx`，方向用 `Mn`。由于 `det(M)=-1`，导出镜像三角网格时交换每面两个顶点，且只交换一次，否则面叉积会与预期法线反向。再次相似配准后，法线再施加对应 proper rotation。

主线存储 face normal，不把显示用的平滑顶点法线误作训练法线。曲面平滑法线只能作为未来单独对照，需特别防止跨牙龈/牙齿边界平均。点采样直接继承所属原面的法线。

**视觉验收**：每颗牙及牙龈分别画稀疏箭头；显示反面、绕序冲突和近邻方向差；前牙切缘、磨牙窝沟、龈缘各有近景。自动要求有限值、单位长度误差建议不超过 `1e-4`，变换法线与重算面法线建议 dot≥`1-1e-5`；几何退化或浮点特殊情况单列。径向负点比例和跨病例方向差只触发复核，不当成临床正确性门槛。

## 整颌对齐与镜像验收

规范坐标主线沿用旧上颌习惯：+X 指向患者左侧，+Y 指向前方，+Z 严格取 X×Y 构成右手系。下颌使用相同定义，不再独立要求上下颌的牙冠方向都为 +Z。每个参考的牙冠实际朝向由可视图标明；不能仅从近共面的牙位质心推断上下翻转。这个坐标系不称为 LPS。

对齐求解使用对应 FDI 的 strict 面积质心，最小化 `Σ ||s R c_k+t-c_ref,k||²`，各牙位等权。SVD 显式处理反射，要求 s>0 和 proper rotation。至少 6 个共同牙位，覆盖双侧及前后区域，作为首批可辨识性要求；近共面可正常存在，主要检查是否近共线、锚点覆盖不足，而不是强制三个奇异值都很大。

参考及统计阈值只用训练病例建立。固定参考不能在逐病例失败时悄悄换成另一例，也不能用非刚性 ICP 把真实排列差异抹平。残差同时给 model 单位与 `residual/s_i` 的病例毫米等价值；该残差反映相对参考的形态/排列差异，不等于预处理损伤。

迭代 GPA 作为后续独立 profile：只更新训练集平均质心，并重新锚定到冻结坐标系；不混用固定参考结果。不得将“残差最小”作为去除错颌、拥挤和大尺寸病例的唯一依据。异常尺度、残差和域占用先触发人工归因，阈值经首批训练病例统计冻结，沿用旧值只能作参考。

第一批原件通过后，镜像分支执行 `canonical reflection → FDI remap → proper similarity realignment to the same reference`。保存反射和再次对齐两段矩阵。旧版没有再次对齐的镜像只用于历史回放，不悄悄当作新版本正确答案。

镜像的几何真实性检查：反射两次及换号两次应还原；再次对齐只是统一缩放和刚体变化，不能改变牙内比例。相对于非对称参考，重新对齐后的镜像不要求与原件逐点重合。`avg_centroids` 根据该 profile 真正导出的训练条目及逐牙有效 presence 计算；若原件和镜像按同权训练，就用该有效集合计算，不能混用“原件均值中心”和另一套镜像坐标。验证/测试及缺牙占位零不能进入统计。

**视觉验收**：至少对多例前牙、前磨牙、磨牙绘制同牙位叠加；病例列表可按残差、尺度和各牙位异常排序；原件/镜像/重对齐三联图展示质心连线、方向箭头和牙号。保留局部自然差异，不以“所有牙重合”作为成功标准。

## 采样库存与训练时采样

两层采样必须分开登记：库存决定可用监督，loader 决定每次真正训练的监督比例。

主线库存沿用论文及旧版：每颗存在牙 25,000 点、牙龈 100,000 点、规范域中 500,000 均匀空间点。缺牙不补造表面；牙龈/腭部与扫描底座的区域范围须先在阶段 1 固定，不能由采样器自行裁切。

表面按各组件合格三角面的面积分布抽面，再用平方根重心公式均匀采样三角形内部。保存 `source_face_id`、三顶点原索引、重心坐标、FDI、置信度、随机算法及种子。所有 profile 共用源几何采样蓝图，之后才变换坐标，使对照不会被重新随机抽点混淆。人工法线翻转和面绕序变化必须同步更新蓝图映射。

空间点在各 profile 声明的 model 域生成；属于非表面约束，不生成伪内外符号。旧接口将其确定性打乱并分成 250,000/250,000 两份：`sdf=0` 是兼容占位，`label=-1` 表示没有组件标签；loader 按 surf/pos/neg 的拼接位置另行生成 `is_on_surf`，其非表面行取 -1，损失据此应用非表面约束。三个字段不能混为一谈；仅修改 label 不会正确生成监督掩码。空间点的 0 占位并非监督“这些点都在零等值面”。不因近表面点偶然存在就批量推离表面；若研究近表面增强或排除带，另建采样对照，不能混入基线。[S5–S7]

第一版 loader 对照采用旧 `20260821` 运行规格，并显式锁定 `SDFSamples(..., load_ram=True)` 分支：每例 8,192 点，其中 4,096 表面点、2,048 来自兼容 pos、2,048 来自兼容 neg；表面从整个表面库存抽取，而不是每牙硬配 256 点。旧 loader 默认 `load_ram=False` 分支只抽 pos/neg，不能当作该基线。全量读取的内存成本另行评估；以后若实现按需加载，也必须证明与此分支的数据契约及采样分布一致，不直接切换默认分支。完整 14 牙情况下，库存为 450,000 表面点，单牙期望约 228 个、牙龈约 910 个；实际按随机 batch 记录，不保证每批恰好该数量。缺牙病例按实际库存改变占比，必须可见。

保留 gum:单牙库存比例 4:1。不得一边沿用旧 loss 名义系数，一边静默把牙龈配额改为与单牙相同。后续若采用逐牙固定配额，必须独立版本化并把训练目标变化作为实验因素。

评估点独立 seed、独立蓝图，与训练抽样不复用记录；仍来自同一真实表面，它只保证采样独立，不等于独立患者。高分辨率质量检查在毫米空间按物理间距设置，建议首批牙冠局部提取目标≤0.2 mm 并做加密稳定性检查，不把全域 48³ 当作细节验收。此值是拟议实验分辨率，不是临床精度承诺。

**视觉验收**：显示真实 loader batch，不只显示漂亮的库存；逐牙计数直方图、面积覆盖热图、切缘和窝沟的局部点云、空间点三正交切片、点到原三角面的精确距离。点到顶点最近距离不作为点落在表面的判据。随机采样不要求覆盖每个小三角面，但不能出现连续解剖区域缺失或系统偏置。

## 导出接口与数值检查

内部事实数据使用带完整元数据的中性格式，不以某个 loader 文件布局作为唯一真相。旧接口适配器单独输出 `SdfSamples/*.npz`（surf/pos/neg/normals）、同名 centroid PKL、`avg_centroids.txt`（50×3）和 split 清单，并以当前核对过的 loader 做读回。PKL 仅限本流程生成的受信任产物。

读回使用真实训练调用入口及 `load_ram=True`，检查 `__getitem__` 的样本、掩码、法线、中心与病例索引嵌套结构；随后核对实际 DataLoader collate 后的 batch。断言每例 4,096 表面行和 4,096 非表面行、逐行标签及掩码对应、中心表按 FDI 索引且缺失有明确约定。非表面法线 `[-1,-1,-1]` 是旧 loader 占位，只验证占位及掩码正确，不纳入表面单位法线验收。

旧上颌适配先验证；下颌标签 31–47 的支持必须检查实际模型 specs 与 loader，不能只改目录名。当前 R4 manifest 适配器必须拒绝将逐病例相似尺度标成固定 50 mm。需要新契约时只在新实验源码/配置副本中开发，保持现有训练与部署路径不变。

自动数值检查包括：顶点和标签一致、面索引有效、有限值、合法 FDI、三角形质量、presence 与实际监督一致、正逆变换、法线单位性及变换一致、面采样重心和为 1、坐标域、float32 写回后仍有效、镜像映射互为逆、患者分组与重复关系、来源及读回哈希。

文件级全部检查；点/法线变换与蓝图关系尽量用分块向量化覆盖全部记录。昂贵的精确几何距离可以用固定、分层的独立 QC 子集，但须公开抽样数量、覆盖牙位、尾部与最坏点，并将不能检查的病例保留为未决。数值通过和视觉通过是两个字段。

## 首批实施顺序和停止条件

1. 先完成来源索引和旧、新实验的历史 train/val/test 使用清单，按患者及重复关系冻结开发组和保留组。在选择参考、查看设计用可视图或调整数据驱动阈值前，确定哪些患者只供开发。新旧共同训练例只用于训练重建诊断，不能声称泛化；开发过程已经查看的历史 test 作为历史比较集，不再宣称是新的盲测集。未来正式盲测需要从未参与当前设计选择的独立患者组；若无这种数据，明确不具备盲测证据。
2. 从开发组建立 12 个诊断患者的名单，目标同时覆盖上下颌；不足成对者明确记缺失，不强行配对。优先覆盖新旧共同病例、正常尺寸两端、拥挤/缺牙、后牙支持较弱及历史被排除的病例。历史异常例进入审核集，不自动进入训练。首批所有参与设计的患者永久留在开发侧；正式全量划分可以后续补齐，但不能再将这些患者分入保留组。保留患者按冻结协议做数据质量审核，不用其结果反调参考、阈值或采样配方；若参与了反调，降为开发数据并记录。
3. 先完成阶段 0–2，每例检查原几何、FDI 和法线；任何未决的问题停止该例的下游导出，不影响其他例继续出待审结果。
4. 冻结参考、坐标和主线尺度选择，完成阶段 3–4；展示固定相似对齐，主线不混入 GPA 或每牙变形。
5. 再完成镜像、库存和实际 loader batch 的审核。所有原件和镜像独立留图，缺少审核记录时不能冻结。
6. 首批通过后，才将同一套协议扩展到全量，记录逐阶段淘汰原因和逐牙有效病例数；阈值调整必须发布新协议并重算受影响结果。
7. 数据冻结后另立训练诊断任务：固定模型和训练预算，先比较单病例/小集合训练重建，再比较训练规模。最终判断依据是与原扫描的逐牙双向表面误差、法线和牙冠细节，不以均值模板看起来整齐或训练 loss 下降替代。

本方案的第一交付物应是这 12 个患者的完整审核包，不是一个直接声明 READY_FOR_TRAINING 的大目录。用户要求的每步可视化验收构成发布条件；程序可以生成检查材料，但不能代替人工记录“已看过并接受”。

## 开始实现前需要落实的具体选择

首批先落实历史使用清单和开发/保留分组；其他需要依据开发组材料冻结的参数包括上/下颌参考病例、实际单位证据、底座/牙龈表面范围、异常法线的病例级处理、对齐残差与尺度告警阈值、模糊边界允许范围。单位未确定时不能进入毫米尺度处理。正式全量划分可后续补齐，但必须遵守已冻结的开发用途及保留边界。

已经确定的默认方向是：独立目录、原件只读、整颌等比相似变换、严格面积质心、面法线、显式 FDI、可重放面积采样、旧 loader 比例基线、镜像单独验收。没有数据依据时，不用自动修复、重新标号或裁剪替代未决项。
